# AURA AI — Intelligent Meeting Insights

Protótipo web interativo do AURA AI para demonstração do Sprint 3.

## Demonstração
- análise de transcrição;
- classificação de sentimento;
- sinais de oportunidade e risco;
- histórico de reuniões;
- insights comerciais;
- comparação de modelos de Machine Learning;
- métricas e matriz de confusão do Sprint 3.

> A interface é uma demonstração visual do conceito de produto. Os indicadores de Machine Learning exibidos na área de modelos correspondem aos resultados obtidos no Sprint 3.
