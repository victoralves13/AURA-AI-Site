# AURA AI — Intelligent Meeting Insights

Protótipo web interativo do AURA AI para demonstração do Sprint 3.

A experiência apresenta análise de transcrição, indicadores comerciais, histórico, insights e os resultados de Machine Learning do Sprint 3.

Os resultados exibidos na área de modelos são os resultados reais obtidos no projeto acadêmico; a análise de transcrição na interface é uma simulação de demonstração do conceito de produto.
