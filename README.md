# AURA AI — Intelligent Meeting Insights

Protótipo web interativo do AURA AI para apresentação do Sprint 3.

A aplicação demonstra o conceito de análise de reuniões, com navegação entre visão geral, nova análise, histórico, insights e performance dos modelos.

Os indicadores da área de Machine Learning correspondem aos resultados reais do Sprint 3. A análise de transcrição da interface é uma simulação de demonstração do conceito de produto.
